# Pickleball Arena Tournament Manager

## Quick Start Guide

**Product:** Pickleball Arena Tournament Manager\
**App:** Pickleball Arena Tournament\
**Guide:** Quick Start\
**Language:** English

------------------------------------------------------------------------

## 1. Overview

Pickleball Arena Tournament Manager helps you create and run pickleball
competitions from a smartphone, tablet, or web browser.

The basic workflow is:

**Create Tournament → Roster → Stage → Setup → Generate → Matches →
Standings / Bracket**

A tournament can contain one or more stages. Each stage defines how its
matches are organized.

The currently supported stage formats are:

-   **Individual Rotation** --- doubles matches with individual player
    rotation and individual standings.
-   **Round Robin** --- group-based competition with generated matches
    and standings.
-   **Elimination** --- single-elimination bracket with optional seeding
    and automatic winner progression.

------------------------------------------------------------------------

## 2. Create a Tournament

From the Home screen, create a new tournament and enter its basic
information.

Give the tournament a clear name so it can be easily identified later.

After creation, open the tournament workspace to manage its roster and
stages.

------------------------------------------------------------------------

## 3. Build the Roster

Open **Roster** and add the players who will participate in the
tournament.

Depending on the competition format, entries can represent individual
players or teams.

Before generating matches, check that:

-   all required participants have been added;
-   player names are correct;
-   teams, where applicable, are correctly composed.

The tournament roster is the source from which stage participants are
selected.

------------------------------------------------------------------------

## 4. Create a Stage

Create a stage and choose the competition format you want to use:

### Individual Rotation

Use Individual Rotation when players compete in doubles matches but the
final ranking is individual.

Players rotate through different combinations of partners and opponents.

### Round Robin

Use Round Robin when participants should play within one or more groups.

The system generates the group matches and calculates the standings from
the recorded results.

### Elimination

Use Elimination for a knockout competition.

Participants are placed into a bracket and winners automatically
progress to the following rounds until the final.

------------------------------------------------------------------------

## 5. Configure the Stage

Open **Setup** and configure the options available for the selected
stage format.

Configuration may include parameters such as:

-   participating players or teams;
-   number of courts;
-   number of rounds;
-   match duration;
-   match format;
-   seeds;
-   stage-specific generation options.

Review the configuration before generating the stage.

Some structural settings should be considered final once matches have
been generated.

------------------------------------------------------------------------

## 6. Generate the Competition

When the setup is complete, select **Generate**.

The application creates the competition structure according to the
selected stage type.

For **Individual Rotation**, this produces the rotation and scheduled
matches.

For **Round Robin**, this produces the groups and their matches.

For **Elimination**, this produces the knockout bracket, taking
configured seeds into account.

Always review the generated structure before starting play.

------------------------------------------------------------------------

## 7. Manage Matches

Open **Matches** to run the competition.

During play you can record match scores and follow the current state of
the tournament.

Depending on the configured match format, matches can use formats such
as **Single Set** or **Best of 3**.

Completed results are used by the application to update the relevant
standings or bracket.

In an Elimination stage, the winner of a completed match automatically
progresses to the appropriate next match.

------------------------------------------------------------------------

## 8. Individual Rotation: Add More Rounds

Individual Rotation is designed to support an open playing session.

After the generated matches have been played, additional rounds can be
added when more playing time is available.

New rounds extend the existing schedule rather than replacing previously
played matches.

This makes Individual Rotation suitable for sessions where the organizer
wants to continue play progressively according to the available time.

------------------------------------------------------------------------

## 9. Check Standings or Bracket

The final navigation depends on the stage format.

### Individual Rotation

Open **Standings** to view the individual ranking produced from the
recorded matches.

### Round Robin

Open **Standings** to follow the ranking within the groups.

### Elimination

Open **Bracket** to view the knockout progression from the opening round
to the final.

Seed numbers are displayed alongside seeded participants, making their
placement and progress easy to identify.

------------------------------------------------------------------------

## 10. Typical Courtside Workflow

For a new competition, the recommended sequence is:

1.  Create the tournament.
2.  Add the participants to the roster.
3.  Create the required stage.
4.  Configure the stage in Setup.
5.  Generate the matches, groups, rotation, or bracket.
6.  Review the generated structure.
7.  Start play and enter results from Matches.
8.  Follow Standings or Bracket as the competition progresses.
9.  Add further rounds when using Individual Rotation and additional
    play is required.
10. Complete the competition when play has finished.

------------------------------------------------------------------------

## 11. Smartphone and Tablet Use

Pickleball Arena Tournament Manager is designed for courtside use.

On a smartphone, navigation is optimized for quick access to the main
tournament sections while matches are being played.

On a tablet, the additional screen space provides a broader view of
structures such as rotations, standings, groups, and elimination
brackets.

The same tournament workflow is maintained across the supported layouts.
